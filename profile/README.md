# Distal

**One chip breaks. Your keys don't.**

Distal keeps the signing keys inside wallets, devices and firmware pipelines safe when a single secure chip is attacked, backdoored or cut off from supply. Secure elements from different vendors sign together, and the private key is never assembled.

- [distal](https://github.com/distalhq/distal): the open applet, protocol spec and (soon) host library
- [site](https://github.com/distalhq/site): the source of [distal.run](https://distal.run) and our brand assets
