# Security policy

Distal protects signing keys, so we take vulnerability reports seriously.

## Reporting a vulnerability

Please do not open a public issue.

1. Use GitHub's private vulnerability reporting on the affected repository (the **Security** tab, then **Report a vulnerability**), or
2. email [hello@distal.run](mailto:hello@distal.run) with the subject "Security report".

Include what you found, how to reproduce it, and which version or commit it affects. We acknowledge reports, work on a fix with you and agree a disclosure date together.

## Scope

This covers the code in the `distalhq` repositories: the applet, the protocol specification and the host library. The protocol is a draft and has not been externally reviewed, so reports about design flaws in the specification are welcome, not only code bugs.
